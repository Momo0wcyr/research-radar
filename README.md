# Research Radar｜课题雷达

一个面向高校导师和课题组负责人的轻量级、离线课题进展看板。

无需服务器、无需数据库、无需 API，也不产生额外费用。导师可以自行维护每个课题的线性进度、关键节点、当前困难、解决方案、下一步行动、汇报时间及学生分工。

## 主要功能

- 导师自定义课题进度百分比和进度条；
- 记录关键节点、困难、解决方案和下一步计划；
- 按状态筛选、搜索和排序课题；
- 显示每日日期及近期汇报提醒；
- 导入、导出 JSON 备份或 AI 更新包；
- 导出桌面总览图片；
- 单个 HTML 文件离线运行，便于复制和分享。

## 快速开始

1. 下载仓库中的 `index.html`。
2. 建议将它重命名为 `课题看板.html`，放在一个长期不变的文件夹中。
3. 使用 Microsoft Edge 或 Google Chrome 双击打开。
4. 点击“新建课题”，由导师录入课题信息并设定进度。
5. 定期点击“导出数据”保存 JSON 备份。

> 数据默认只保存在当前浏览器中。更换电脑、浏览器、文件位置或文件名之前，请先导出 JSON 备份，再在新环境中导入。

完整说明见 [课题看板使用说明](docs/课题看板使用说明.md)。

## AI 辅助更新方式

推荐流程：学生把阶段性工作总结交给导师，导师将总结和看板导出的 JSON 备份交给 AI；AI 整理为更新包后，再由导师审核并导入看板。该流程不需要配置 API。

## 隐私说明

本仓库仅包含空白模板，不含真实学生信息、实验数据或课题内容。使用者应自行妥善保管导出的 JSON 备份，避免将包含敏感研究信息的备份上传到公开仓库。
